# 금일 학습 내용

오늘은 클로드 코드와 함께 마크다운을 블로그로 변환하는 사이트를 만들면서, HTML/CSS/JavaScript가 각각 어떤 역할을 맡는지 다시 한번 정리해봤다.

## HTML — 구조

페이지의 뼈대를 담당한다. `index.html`은 글 목록을 보여줄 자리(`<main>`, `<div id="post-list">`)를, `post.html`은 글 본문이 들어갈 자리(`<article id="post-content">`)를 잡아준다. 내용 자체는 비워두고, 나중에 JavaScript가 채워 넣는 구조다.

## CSS — 디자인과 반응형

색상, 여백, 글꼴 같은 시각적인 부분을 담당한다.

- CSS 변수(`--bg`, `--text` 등)로 색상을 정의해두면, `data-theme="dark"` 속성 하나만 바꿔서 다크모드 전체를 한꺼번에 전환할 수 있다.
- `clamp()`와 미디어 쿼리를 이용해 화면 크기에 따라 폰트 크기와 여백이 자연스럽게 줄어들도록 만들어, 모바일에서도 읽기 편하게 했다.

## JavaScript — 동작과 데이터 처리

실제 동작과 데이터 흐름을 담당한다.

- `fetch()`로 마크다운 파일과 `posts.json`을 읽어온다.
- 프론트매터(제목, 날짜, 요약)를 파싱해서 목록 카드와 글 상세 페이지에 채워 넣는다.
- `marked.js`로 마크다운 본문을 HTML로 변환해 화면에 보여준다.
- 다크모드 토글 버튼 클릭을 감지하고, 선택한 테마를 `localStorage`에 저장해 다음 방문에도 유지되게 한다.

## 정리

결국 HTML은 "어디에 무엇이 들어갈지"를, CSS는 "어떻게 보일지"를, JavaScript는 "어떤 데이터로 무엇을 할지"를 담당한다는 걸 직접 만들면서 다시 체감할 수 있었다.
